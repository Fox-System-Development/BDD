<h2 id="info">Descrição do Projeto</h2>


 Projeto desenvolvido com intuito de aplicar testes na modalidade BDD.

 Aplicar os testes para verificar a lógica das funcionalidades apresentadas, utilizando a visão do usuário com histórias.
